4️⃣ Database Design (Prisma Schema)
model User {
  id        String   @id @default(uuid())
  email     String   @unique
  name      String?
  createdAt DateTime @default(now())
  reviews   Review[]
  plan      Plan     @default(FREE)
}

model Review {
  id          String   @id @default(uuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  language    String
  code        String   @db.Text
  result      Json
  createdAt   DateTime @default(now())
}

enum Plan {
  FREE
  PRO
}
5️⃣ AI Prompt Engineering (CRITICAL)

We NEVER return raw text.

We force structured JSON:

{

  complexity: {
    time: string,
    space: string,
    explanation: string
  },
  cleanCode: string[],
  security: string[],
  optimization: string[],
  improvedCode: string
}

This makes UI clean and scalable.

6️⃣ Security Considerations

This is important.

🚨 Risks:

Prompt injection via code comments

Code execution attacks

Abuse of API quota

XSS via rendered output

✅ Fixes:

Never execute user code

Escape all AI outputs before rendering

Rate limit per IP + per user

Validate input size (max 5k chars for free users)

Sanitize Markdown before rendering
